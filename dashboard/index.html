This viewer renders a scoring or practice run from the agent's per-touch trace (D-Q) and the cross-session playbook (D-P). It reads local files only — no network, no API, nothing leaves this page.

  • Open trace… — pick a .jsonl session trace from agent/traces/ (multi-select works), or drag & drop files anywhere on this page.
  • Open playbook… — pick agent/playbook.json to see cross-session memory.
  • Load sample — render the bundled sample session to preview the layout.
  • Serve the project root (python3 -m http.server 8123) and open /dashboard/ to get a clickable list of agent/traces/ automatically, or deep-link with ?trace=../agent/traces/<file>.jsonl.

Scrub with ← / → arrow keys once a session is loaded.
